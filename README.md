# 건자재·하우징 MD 안내 포털

협력사가 입점 제안을 준비할 때 필요한 안내를 한 페이지에 모아 둔 포털입니다. 카테고리 확인, 추천 상품, 입점 절차, 자가진단, 가격 구성 계산, FAQ, 자료 내려받기를 한 곳에서 할 수 있습니다.

## 열어 보기

`index.html`을 더블클릭하면 브라우저에서 열립니다. 별도 설치나 서버는 필요 없고, 외부 주소를 불러오지 않아 인터넷이 연결되지 않아도 열립니다. 다른 사람에게 보낼 때는 `index.html` 파일 하나만 전달해도 됩니다.

## 화면 구성

위쪽 메뉴를 누르면 해당 영역으로 이동하고, 스크롤하면 지금 보고 있는 메뉴가 강조됩니다. 휴대폰처럼 화면이 좁으면 메뉴가 가로로 밀립니다.

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 포털 소개와 바로가기 버튼(입점 절차 보기, 가격 구성 연습하기) |
| 카테고리 | 창호, 바닥재, 욕실, 주방, 단열·마감재 5개 카테고리 안내 |
| 추천 상품 | 추천·신규 상품 카드 3개 |
| 입점 절차 | 5단계 절차와 입점 제안 전 자가진단 |
| 계산기 | 가격 구성 연습 계산기 |
| FAQ | 협력사 자주 묻는 질문 10개와 검색 |
| 자료실 | `files` 폴더의 자료 목록(파일명·설명·용량)과 내려받기 |

## 기능별 사용법

### 카테고리 필터

"전체", "창호", "바닥재", "욕실", "주방", "단열·마감재" 버튼으로 보고 싶은 분야만 모아 볼 수 있습니다. 하나를 고르면 그 카테고리 카드 하나가 크게 보이고, "소싱 시 확인 포인트"가 함께 펼쳐집니다. "전체"를 누르면 다시 5개 카드가 보입니다.

### 입점 제안 전 자가진단

해당하는 항목을 체크하면 8개 중 몇 개를 준비했는지 퍼센트와 막대로 보여 주고, 진행 정도에 맞는 안내 문구가 바뀝니다. "초기화" 버튼으로 모두 해제할 수 있습니다. 체크 내용은 저장되지 않으므로 페이지를 새로 고치면 처음 상태로 돌아갑니다.

### 가격 구성 연습 계산기

1. 매입가를 입력합니다(원).
2. 물류비를 입력합니다(원). 비워 두면 0원으로 계산합니다.
3. 마진율을 입력합니다(%).
4. 마진율 기준을 고릅니다.
   - 판매가 기준: 판매가 = 원가 ÷ (1 − 마진율)
   - 원가 기준: 판매가 = 원가 × (1 + 마진율)

입력하는 동안 결과가 바로 바뀝니다. 결과에는 원가(매입가 + 물류비), 예상 판매가, 마진 금액, 판매가 대비 실제 마진율, 참고용 부가세(10%) 포함가가 표시됩니다. 금액은 원 단위로 반올림하며 판매가는 부가세 별도 기준입니다.

판매가 기준에서 마진율을 100% 이상으로 넣거나 0보다 작은 값을 넣으면 오류 문구가 나옵니다. 이 계산기는 가격을 구성해 보는 연습용이며 실제 거래 가격이 아닙니다.

예: 매입가 100,000원, 물류비 5,000원, 마진율 25%(판매가 기준)이면 원가 105,000원, 예상 판매가 140,000원, 마진 금액 35,000원입니다.

### FAQ 검색

검색창에 단어(예: 샘플, 결제, 인증)를 입력하면 분류·질문·답변에 그 단어가 들어간 항목만 남고, 결과 건수가 표시됩니다. 일치하는 글자는 노란색으로 표시되고 해당 답이 자동으로 펼쳐집니다. 결과가 없으면 "검색 결과가 없습니다"라는 안내가 나옵니다. 검색하지 않을 때는 질문을 눌러 답을 펼칩니다.

### 자료실 내려받기

자료실에는 `files` 폴더의 자료가 목록으로 나타납니다. 지금 들어 있는 두 문서(입점 제안 가이드, 입점 제안서 양식)는 내용을 바꿔 쓰기 위한 샘플이므로, 실제 자료로 교체한 뒤 용량도 다시 적어 주세요. 한 줄에 파일 종류(PDF, DOCX 등), 파일명, 설명, 용량, "다운로드" 버튼이 있습니다. 버튼을 누르면 새 창이 열리지 않고 바로 내려받아지며, 저장되는 이름은 목록에 보이는 한글 파일명입니다. 등록된 자료가 없으면 "등록된 자료가 없습니다"라고 나옵니다.

브라우저는 폴더 안 파일을 스스로 읽어 목록을 만들 수 없어서, 목록은 `index.html` 안의 표(`FILES`)에 적은 내용으로 만들어집니다. 자료를 추가하는 방법은 아래 "내용 바꾸기"를 보세요.

**열어 보는 방법에 따라 달라지는 점**: `index.html`을 더블클릭해서(주소가 `file://`로 시작) 열면 크롬이 다운로드 설정을 무시해, PDF가 새 창이 아니라 같은 탭에서 열리고 Word 파일은 영문 파일명으로 저장되는 것을 확인했습니다. 웹 서버나 사내 주소(`http://`, `https://`)로 열면 의도한 대로 PDF도 바로 내려받아지고 한글 이름으로 저장됩니다. 포털을 구성원에게 공유할 때는 서버나 사내 공유 주소에 올리는 것을 권합니다.

## 내용 바꾸기

텍스트 편집기(메모장 등)로 `index.html`을 열어 수정합니다. 수정 전에 파일을 복사해 두세요.

- **예시 문구**: 추천 상품 3개(이름, 특징, 이미지)와 FAQ 답변은 예시입니다. 화면 아래에도 "실제 정보로 교체해 사용하세요"라고 안내되어 있으니 실제 내용으로 바꿔 주세요.
- **자료실에 자료 추가**: 1) `files` 폴더를 만들고 파일을 넣습니다. 파일명은 한글·공백 없이 영문 소문자와 하이픈으로 짓습니다(예: `entry-guide.pdf`). 2) `index.html`에서 `var FILES = [` 부분을 찾아 파일마다 한 줄을 적습니다. 3) 용량은 파일 속성에서 확인해 직접 적습니다.

  ```
  var FILES = [
    { file: 'entry-guide.pdf', name: '입점 제안 가이드.pdf', desc: '입점 절차와 제안서 작성 요령을 정리한 안내서입니다.', size: '1.2 MB' },
    { file: 'entry-form.docx', name: '입점 제안서 양식.docx', desc: '회사·상품·거래 조건을 채워 제출하는 기본 양식입니다.', size: '38 KB' },
  ];
  ```

  - `file`: `files` 폴더 안의 실제 파일명입니다. 링크는 `files/파일명`으로 걸립니다.
  - `name`: 화면에 보이고, 내려받을 때 저장되는 한글 파일명입니다. 확장자까지 적습니다.
  - `desc`, `size`: 설명과 용량입니다.
  - 파일을 바꾸거나 지울 때는 해당 줄도 함께 고칩니다. 줄이 없는 파일은 목록에 나타나지 않습니다.

## 폴더 구성

```
index.html             포털 본체
README.md              이 안내문
이전버전/portal-v2.html  이름을 바꾸기 전 원본(부서포털_v2.html)의 사본
files/                 자료실에 올릴 PDF·Word 자료(자료가 생기면 만드세요)
```
