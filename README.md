# 하우징플랫폼 — 건축의 모든 것을 잇다

유진기업 하우징플랫폼 건자재 사업 소개 자료(PDF)를 바탕으로 만든 부서 포털 홈페이지입니다. 이 페이지에 있는 글과 숫자, 이미지는 모두 그 자료에서 가져왔습니다.

## 열어 보기
`index.html`을 더블클릭하면 브라우저에서 열립니다. `files/img` 폴더(이미지)가 같은 위치에 있어야 사진이 보입니다.

## 화면 구성
| 메뉴 | 내용 |
|---|---|
| 홈 | 제목, 도심 사진, 핵심 수치 3개(1954 / 2,700억원 / 300+) |

| 사업 영역 | 하우징플랫폼 매출, 에이스하드웨어, 설비자재, 레미콘 수치 |

## 기능
- **공정별 필터**: 버튼으로 Part를 골라 볼 수 있고, 분류 이름을 누르면 세부 품목이 펼쳐집니다.
- **다크 모드**: 오른쪽 위 ☾/☀ 버튼. 처음에는 기기 설정을 따르고, 고른 값은 이 브라우저에 기억됩니다.
- **맨 위로 버튼**: 아래로 내려가면 오른쪽 아래에 ↑ 버튼이 나타납니다.
- **모바일 ≡ 메뉴**, 현재 위치 메뉴 강조.

## 내용 바꾸기
- 글은 `index.html`에서 해당 문장을 찾아 고칩니다. 공정별 자재는 `part` 블록(`id="part01"` ~ `part05`), PB 브랜드는 `class="card prod"` 블록입니다.
- 이미지는 `files/img` 안의 같은 이름 파일로 바꿔 넣으면 됩니다.
- 색은 `index.html` 위쪽 `:root`(라이트)와 `html[data-theme="dark"]`(다크)에 모여 있습니다.

## 폴더 구성
```
index.html
README.md
files/
  preview.png   링크 미리보기(OG) 이미지 1200×630
  img/          소개 자료에서 가져온 사진
```

## 공개 전 확인
- 링크 미리보기 이미지 주소는 임시 값(`https://portal.example.com/`)입니다. 실제 공개 주소가 정해지면 `index.html` 위쪽 `og:url`, `og:image`, `twitter:image`를 바꿔 주세요.
- 사진은 회사 소개 자료의 이미지입니다. 외부에 공개하기 전에 사용 허락 범위를 확인하세요.
